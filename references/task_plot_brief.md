# Task Plot Brief

## Task

- Title: Cambridge Gambling Task
- Construct: risk decision making / probability judgment / betting behavior
- Paradigm: explicit red/blue probability judgment followed by proportional bet selection.

## Rows

- High ratio: 9:1 red/blue box split.
- Medium ratio: 8:2 or 7:3 red/blue box split.
- Low ratio: 6:4 red/blue box split.

## Trial Timeline

1. Fixation: 300-600 ms jittered fixation, no response.
2. Color choice: 3000 ms. Show 10 boxes and ratio. Press F for red, J for blue.
3. Bet choice: 3500 ms. Select bet percentage with keys 1-5.
4. Feedback: 1000 ms. Reveal token color, applied stake, point delta, and updated score.
5. ITI: 300-600 ms jittered fixation, no response.

## Notes

- Box ratios are sampled from 9:1, 8:2, 7:3, and 6:4.
- Bet options are 5%, 25%, 50%, 75%, and 95%.
- Bet order is ascending or descending by block.
- Color timeout causes no bet and no score change; bet timeout auto-selects the last displayed percentage.
